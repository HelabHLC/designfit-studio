# Runtime master v1

The checksum-locked `runtime-master-v1.csv` is included for the WordPress
reference lookup. It contains 13,283 unique HLC references and has SHA-256
`9baa2cdfe75e3489fc94bc92377f5b0509f2f5688a279d92c1201559757f7fd4`.

Read `RELEASE_NOTICE.md` for freieFarbe attribution, the publisher's
database-product zlib licence, the package readme's CC BY-ND statement and
the ARBE additions. `runtime-master-v1.release-manifest.json` records the
source hashes, schema and verification. The legacy candidate manifest is
retained as a superseded audit record.

Run `python tools/validate_runtime_master.py` before packaging or import.
